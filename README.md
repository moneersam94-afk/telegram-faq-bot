# مساعد ويلث إكسل على تلجرام

بوت مساعد شخصي وغير رسمي، يعمل مجانًا على Render. القائمة الرئيسية فيها 4 خانات:

| الخانة | ماذا تفعل |
|---|---|
| ⏰ منبه الصفقات اليومية | تذكير تلقائي بموعد الصفقة (3:30–5:30 م GMT) وجمع الأرباح (6:30–8:30 م GMT) |
| 📚 الشروحات | مواضيع تعرض منشورات قناة الشروحات (فيديو ووصف) |
| ❓ الأسئلة الشائعة | أقسام ← أسئلة ← جواب. ويفهم السؤال المكتوب بصياغات مختلفة |
| ✅ الحسابات المعتمدة | القنوات والقروبات وحسابات الوكلاء الرسمية (`accounts` في content.json) |
| 🛠 الإبلاغ عن مشكلة | يختار الشخص نوع المشكلة فيحوّله البوت للمختص بها |

الأقسام الفارغة تظهر برسالة «🚧 هذا القسم قيد الإنشاء».

كل النصوص في ملف واحد: [bot/content.json](bot/content.json).

## ⏰ منبه الصفقات

- تنبيه عند فتح الموعد بالضبط، مع زرّي «✅ تمّ» و«😴 ذكّرني بعد 5 دقائق».
- كل موعد متاح لساعتين (`duration_minutes`). يظهر للمشترك من متى إلى متى بتوقيته، ولو تأخر السيرفر يصله التنبيه ما دام الموعد مفتوحًا.
- تنبيه أخير قبل الإغلاق بـ15 دقيقة (`closing_reminder_minutes`) يصل فقط لمن لم يضغط «تمّ».
- تذكير مسبق يختاره المشترك: بدون، أو قبل 5 أو 10 أو 15 أو 30 دقيقة أو ساعة.
- يختار المشترك بلده، فتظهر المواعيد بساعته المحلية مع حساب التوقيت الصيفي تلقائيًا.
- يختار التنبيهات التي يريدها: الصفقة، أو الأرباح، أو الاثنين.
- إيقاف مؤقت ليوم أو 3 أيام أو أسبوع، ثم يرجع المنبه وحده.
- زر «جرّب التنبيه» وعدّاد للتنبيه القادم.
- من يحظر البوت يُلغى اشتراكه تلقائيًا، والإرسال الجماعي يحترم حدود تلجرام.

لتغيير المواعيد عدّل `time_gmt` (بتوقيت غرينتش وبنظام 24 ساعة، مثل `15:30` للساعة 3:30 مساءً).
ولتحديد الأيام عدّل `days`، مثلًا من الاثنين إلى الجمعة: `["mon","tue","wed","thu","fri"]`.

**حفظ المشتركين:** سيرفر Render المجاني يمسح ملفاته عند كل نشر، لذلك يحفظ البوت بيانات المشتركين
كملف مثبّت في محادثة المدير مع البوت (رسالة واحدة تتحدث تلقائيًا، لا تحذفها).
هذا يتطلب ضبط `ADMIN_IDS` (انظر الأسفل). بدونه تضيع الاشتراكات عند كل نشر.

## 💬 المنبه في القروبات

1. أضف البوت للقروب **من حساب المدير** (لو أضافه غيرك يخرج تلقائيًا).
2. اجعله مشرفًا بصلاحيتي **تثبيت الرسائل** و**حذف الرسائل**.
3. يصلك تأكيد في الخاص، وتدير القروبات بالأمر `/groups` (إيقاف، تجربة، إخراج البوت).

لكل موعد 3 رسائل: عند الفتح (مثبّتة)، وتنبيه أخير قبل الإغلاق بـ15 دقيقة (مثبّتة)،
ورسالة «انتهى الموعد» عند الإغلاق (غير مثبّتة، وفيها الموعد القادم).
كل رسالة تحذف رسالة البوت السابقة فقط، فيبقى في القروب دائمًا تنبيه واحد من البوت.
رسائل الأعضاء والبرودكاست والرسالة التجريبية لا تُحذف أبدًا.
العبارات العفوية في `group_open` و`group_close` و`group_end` لكل موعد، ويختار البوت منها عشوائيًا.

## 📚 إضافة شرح أو فيديو

```json
"topics": [
  {
    "title": "📊 اسم الموضوع",
    "text": "نص الشرح",
    "videos": ["https://t.me/c/1234567890/5"],
    "buttons": [{ "text": "▶️ الشرح على يوتيوب", "url": "https://youtube.com/..." }]
  }
]
```

أفضل طريقة للفيديو: **قناة خاصة** ترفع عليها الفيديوهات مرة واحدة.
1. أنشئ قناة خاصة وأضف البوت مشرفًا فيها (سيكتب البوت في القناة معرّفها).
2. ارفع الفيديو في القناة، ثم اضغط عليه ← **Copy Post Link** وضع الرابط في `videos`.

البوت ينسخ المنشور للشخص فورًا بدون إعادة رفع، وبدون عبارة "محوّل من"، وأي حجم للفيديو.
طريقة بديلة: أرسل الفيديو للبوت من حساب المدير، فيرد عليك بمعرّف جاهز للنسخ في `videos`.

## 🛠 أنواع المشاكل

```json
{ "title": "💳 مشكلة في الإيداع أو السحب", "contact": "@username", "hints": ["رقم العملية"] }
```
`contact` يوزر تلجرام (يظهر له زر مراسلة مباشر) أو أي نص. إذا تركته فارغًا يظهر «سيتم إضافته قريبًا».
`hints` اختياري، وإذا لم تكتبه تُستخدم القائمة العامة.

## ❓ الأسئلة الشائعة

```json
"categories": [
  { "title": "💳 الإيداع والسحب", "questions": [
    { "q": "كيف أسحب أرباحي؟", "a": "الجواب", "keywords": ["سحب", "اسحب", "ارباح"] }
  ]}
]
```
أضف كلمات مفتاحية كثيرة بأكثر من لهجة، فهي التي تجعل البوت يفهم السؤال حين يُكتب بصيغة مختلفة.

بعد أي تعديل تأكد أن الملف سليم:
```powershell
python -m unittest discover tests
```

## 👑 المدير

أرسل للبوت `/myid` لتعرف معرّفك، وضعه في متغير `ADMIN_IDS` على Render. بعدها تصير لك أوامر:
- `/stats` عدد المستخدمين والمشتركين.
- `/broadcast` ردّ به على أي رسالة لإرسالها لمشتركي المنبه، أو كل المستخدمين، أو القروبات، أو الكل.
- `/send @username` مراسلة مستخدم معيّن، و`/user اسم` للبحث. رسالتك تصله مع زر «↩️ الرد على الإدارة»،
  وإذا ضغطه وكتب ردًا يصلك في الخاص مع زر للرد عليه. (تلجرام يسمح بمراسلة من بدأ البوت فقط.)
- `/groups` إدارة القروبات.
- `/testalarm` تجربة شكل التنبيه.
- أرسل فيديو أو حوّل منشورًا من قناتك ← يرد البوت بالمعرّف أو الرابط الجاهز.

## النشر على Render

1. **Web Service** من مستودع GitHub: Runtime `Python`، Plan `Free`،
   Build `pip install -r requirements.txt`، Start `python -m bot.server`.
2. متغيرات **Environment**:
   - `TELEGRAM_BOT_TOKEN` التوكن من BotFather (إجباري).
   - `ADMIN_IDS` معرّفك من `/myid` (ويمكن أكثر من معرّف مفصولة بفواصل).
   - `STORAGE_CHAT_ID` اختياري: قناة خاصة لحفظ البيانات بدل محادثة المدير.
   - `KEEP_AWAKE_MINUTES` اختياري: الافتراضي 10، و`0` يوقف خاصية الإبقاء مستيقظًا.
3. للتأكد افتح `https://اسم-الخدمة.onrender.com/setup`.

بعد أي تعديل على GitHub اضغط في Render **Manual Deploy → Deploy latest commit**
(أو اربط حساب GitHub بـ Render من Account Settings → Git ليصير النشر تلقائيًا).

السيرفر يزور نفسه كل 10 دقائق فلا ينام أبدًا، وهذا ضروري حتى تصل تنبيهات المنبه في وقتها.

## التشغيل المحلي (اختياري)

يحتاج VPN على مستوى الجهاز كله. ضع التوكن في `.env` ثم `python run_local.py`.
التشغيل المحلي يفصل الـ webhook، فافتح رابط `/setup` على السيرفر بعدها لإعادة الربط.

## الملفات

- `bot/content.json` المحتوى كله.
- `bot/core.py` القوائم والبحث والردود.
- `bot/alarm.py` منبه الصفقات والجدولة.
- `bot/storage.py` حفظ البيانات على تلجرام.
- `bot/admin.py` أوامر المدير والرسائل الخاصة.
- `bot/groups.py` تنبيهات القروبات وإدارتها.
- `bot/server.py` سيرفر Render. `bot/telegram.py` الاتصال بتلجرام. `bot/ui.py` أدوات الأزرار.
- `.env` أسرارك. **لا ترفعه ولا تشاركه.**
