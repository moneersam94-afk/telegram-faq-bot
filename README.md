# بوت الأسئلة الشائعة على تلجرام

بوت شخصي غير رسمي يجيب على الأسئلة الشائعة عن شركة معينة، باستخدام أسئلة وأجوبة ثابتة.

- قائمة أزرار: أقسام ← أسئلة ← جواب.
- يفهم الأسئلة المكتوبة بصياغات مختلفة عن طريق الكلمات المفتاحية، ويتعامل مع الهمزات والتاء المربوطة و"ال".
- زر "تواصل مع شخص" للأسئلة التي ليس لها جواب.
- يرد في المحادثات الخاصة فقط.
- لا يحتاج أي مكتبة خارجية، ويعمل مجانًا على Render.

## 1) تعديل الأسئلة والأجوبة

كل المحتوى موجود في ملف [bot/faq.json](bot/faq.json):

| الحقل | معناه |
|---|---|
| `company_name` | اسم الشركة، ويُكتب مكان `{company}` في أي نص |
| `welcome` | رسالة الترحيب |
| `disclaimer` | تنبيه أن البوت غير رسمي (اتركه) |
| `fallback` | الرد حين لا يجد البوت جوابًا |
| `human_contact` | طريقة التواصل مع شخص. احذف الحقل إذا لا تريد الزر |
| `categories` | الأقسام، وفي كل قسم قائمة `questions` |

كل سؤال يتكون من:
```json
{ "q": "نص السؤال كما يظهر على الزر", "a": "الجواب", "keywords": ["كلمة", "عبارة من كلمتين"] }
```
أضف كلمات مفتاحية كثيرة بأكثر من لهجة (وين، أين، فين…)، فهي التي تجعل البوت يفهم السؤال حين يُكتب بصيغة مختلفة.

بعد أي تعديل، تأكد أن الملف سليم بهذا الأمر:
```powershell
python -m unittest discover tests
```
(الاختبارات مكتوبة على الأسئلة التجريبية. إذا غيّرت الأسئلة وفشلت اختبارات البحث فقط فهذا طبيعي، المهم أن ينجح `test_loads_and_callback_data_fits`.)

## 2) النشر المجاني على Render

1. ارفع المشروع إلى مستودع على GitHub.
2. في Render أنشئ **Web Service** من المستودع بهذه الإعدادات:
   - Runtime: `Python` — Plan: `Free`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python -m bot.server`
3. في **Environment** أضف متغيرًا واحدًا: `TELEGRAM_BOT_TOKEN` وقيمته التوكن من BotFather.
4. عند التشغيل يربط السيرفر نفسه بتلجرام تلقائيًا. للتأكد افتح:
   `https://اسم-الخدمة.onrender.com/setup` ← يجب أن تظهر **✅ البوت @… يعمل**.

بعد أي تعديل على GitHub (مثل تعديل `faq.json`) افتح الخدمة في Render واضغط **Manual Deploy → Deploy latest commit**.
إذا ربطت حساب GitHub بـ Render (Account Settings → Git) يصير النشر تلقائيًا.

**الإبقاء مستيقظًا:** الخطة المجانية تنام بعد 15 دقيقة بدون طلبات. لذلك يزور السيرفر رابطه بنفسه
كل 10 دقائق فيبقى مستيقظًا دائمًا (750 ساعة مجانية في الشهر تكفي لخدمة واحدة طوال الشهر).
لتغيير المدة أضف المتغير `KEEP_AWAKE_MINUTES`، ولإيقاف الخاصية اجعل قيمته `0`.

## 3) التشغيل المحلي (اختياري)

يحتاج اتصالًا يصل لتلجرام، أي VPN على مستوى الجهاز كله وليس إضافة متصفح فقط. ضع التوكن في `.env` ثم:
```powershell
python run_local.py
```
تنبيه: التشغيل المحلي يفصل الـ webhook. بعد الانتهاء افتح رابط `/setup` على السيرفر لإعادة الربط.

## الملفات

- `bot/core.py`: منطق البوت (القوائم، البحث، الردود).
- `bot/faq.json`: المحتوى.
- `bot/server.py`: سيرفر الـ webhook على Render.
- `run_local.py`: التشغيل على جهازك.
- `tests/`: اختبارات تعمل بدون إنترنت.
- `.env`: أسرارك. **لا ترفعه ولا تشاركه** (مستثنى في `.gitignore`).
